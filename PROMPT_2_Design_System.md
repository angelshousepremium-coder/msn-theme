# Этап 2 — Design System & Visual Strategy

## Роль

Ты — senior UI/UX designer специализирующийся на industrial B2B premium сегменте.

## Задача

Разработать полную визуальную стратегию и design system для WooCommerce сайта производителя спецтехники. Результат этого этапа станет обязательным документом-конституцией для этапов 3 и 4 — разработчик будет реализовывать строго в рамках принятых здесь решений.

**НЕ пиши PHP/HTML код шаблонов.** Только design system и CSS-токены.

---

## Контекст бизнеса

- Производитель и официальный дилер спецтехники на базе автомобилей Урал
- Типы продукции: фургоны, автоцистерны, вахтовые автобусы
- Сегмент: B2B, heavy industry
- Средний чек: 3–15 млн рублей
- Целевая аудитория: руководители предприятий, снабженцы, логисты, инженеры

Дизайн-система будет реализована внутри:

- Ломать WooCommerce хуки
- Переименовывать существующие CSS-классы

## Что нужно разработать

### 1. Принципы визуального языка
- 3–5 UI-принципов специфичных для этого сегмента
- Чего избегать (glassmorphism, neon, startup aesthetics, giant shadows, excessive border-radius, gradients)
- Как передать ощущение надёжности и масштаба через типографику, отступы, цвет

### 2. Typography system
- Размеры заголовков h1–h4 (desktop и mobile)
- Font-weight для каждого уровня (Montserrat для заголовков, Manrope для тела)
- Line-height и letter-spacing
- Иерархия текстовых стилей: заголовок страницы, подзаголовок, лид-текст, body, caption, label
- CSS-переменные для всех размеров

### 3. Spacing system
- Базовый шаг (8px или 4px grid)
- Отступы между секциями страницы
- Внутренние отступы карточек, панелей, контейнеров
- Gap между карточками в сетке
- CSS-переменные для spacing

### 4. Card system — карточка товара в листинге
- Пропорции: соотношение фото к информационной части
- Рамка, тень, border-radius
- Hover-состояние: zoom фото, overlay, тень
- Кнопка "Подробнее" — где, как появляется
- Отображение цены и названия
- Что должно чувствоваться: дорого, промышленно, надёжно

### 5. CTA system — иерархия кнопок
- Primary: "ПОЛУЧИТЬ КП" — параметры (высота, padding, font-size, weight, uppercase, цвет)
- Secondary ghost: "РАССЧИТАТЬ ЛИЗИНГ" — параметры
- Tertiary link: "Скачать PDF" — параметры
- Hover-состояния для каждого
- Sticky CTA-панель: поведение при скролле, содержимое, позиция (top/bottom)
- Правило: когда оранжевый, когда тёмный фон, когда ghost

### 6. Sidebar & filter UX
- Вертикальный sidebar с навигацией по категориям (.ver-tabs)
- Активное состояние: оранжевая левая полоска или подчёркивание
- Hover с плавным фоном
- Блок фильтров (.filter-tehnika): как стилизовать под дизайн-систему

### 7. Product gallery UX
- Главное фото + горизонтальные миниатюры снизу
- Lightbox через Magnific Popup (не PhotoSwipe — он не инициализирован)
- Transition при смене фото (fade или slide)
- Поведение на мобильном (swipe, thumbnails)

### 8. Product tabs UX
- Горизонтальные вкладки: как выглядит активная (оранжевая полоска снизу 3px vs фон vs рамка)
- Неактивные вкладки: цвет, hover
- Контент таба: отступы, фон, тень
- Таблицы характеристик: чередующиеся строки, разделители, без внешней рамки
- Галерея внутри таба: сетка миниатюр, lightbox с навигацией (исправление UX-бага)
- Мобильное поведение: горизонтальный скролл вкладок или аккордеон

### 9. Motion system
- Hover-анимации: какие transition, какие duration
- Карточки: transform + box-shadow (рекомендуемые параметры)
- Кнопки: hover + active (click feedback)
- Sticky-панель: как появляется (slideDown, fade, сразу)
- Табы: смена контента (fade, instant)
- Правило: анимации должны быть деловыми, не игривыми. Max duration 300ms.

### 10. Trust & brand blocks
- Блок .about-feature (4 преимущества): тёмный фон vs светлый, иконки, spacing
- Секция .why (5 карточек "Почему выбирают нас"): фон секции, карточки, hover
- Форма обратной связи .blok_zvonok_form: фон, заголовок, поля, кнопка

### 11. Mobile UX strategy
- Breakpoints (< 768px, 768–1024px, > 1024px)
- Страница категории: sidebar скрывается или становится dropdown?
- Страница товара: галерея + summary — порядок на мобильном
- Табы на мобильном: горизонтальный скролл или аккордеон (аргументировать выбор)
- Кнопки CTA на мобильном: полная ширина?

### 12. Visual hierarchy — итог
Опиши как выглядит страница товара сверху вниз с точки зрения визуального веса: что притягивает взгляд первым, вторым, третьим. Это будет чек-листом для разработчика.

## UX-приоритеты (в порядке важности)

1. Readability — текст должен легко читаться с первого взгляда
2. Fast scanning — B2B-клиент сканирует, не читает
3. Specification access — технические характеристики должны быть быстро доступны
4. CTA clarity — один понятный следующий шаг всегда виден
5. Technical trust — сайт должен внушать доверие к производителю
6. Aesthetics — красота на последнем месте, работает в связке с остальными

---

## Формат ответа

Дай полноценный документ design system:

1. **UI Principles** — 4–5 принципов с объяснением
2. **Color rules** — правила применения существующих цветов + CSS-токены если нужны новые
3. **Typography scale** — полная таблица + CSS-переменные
4. **Spacing scale** — система отступов + CSS-переменные
5. **Component specs** — для каждого компонента: параметры, состояния, правила
6. **Motion rules** — таблица: элемент → transition → duration → easing
7. **Mobile rules** — breakpoints + поведение каждого ключевого компонента
8. **Visual hierarchy map** — как выглядит страница товара сверху вниз

CSS-переменные и токены — **приветствуются и обязательны**. PHP/HTML-код шаблонов — не нужен.
